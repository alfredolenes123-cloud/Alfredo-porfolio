# Alfredo Lenes Portfolio

A responsive portfolio for Alfredo Lenes González — Senior Software Developer, .NET Specialist and Technical Lead.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Upload this folder to GitHub.
2. Import the repository in Vercel.
3. Vercel detects Vite automatically.
4. Deploy.

The English CV is included in `/public/Alfredo_Lenes_CV_English.pdf`.
